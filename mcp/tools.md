# wsm-mcp tools

Generated by `go run ./cmd/wsm-mcp tools` (wsm-mcp 0.3.0, 93 tools). Danger-gated tools refuse
unless WSM_MCP_ALLOW_DANGEROUS=true. Every result is `{"host": "...", ...}` naming which configured host answered.

## `waxum_appstate_resync`
Force waxum to resync app-state collections (contacts, chat metadata) for a session.

Wraps: `waxum.Client.AppStateResync`

- `session_id` string — WSM session id. Either this or phone is required for session-scoped routes; if both are given, session_id wins. Per-host: the SAME phone has a DIFFERENT session_id on each configured host (see wsm_resolve_session).
- `phone` string — Phone number (any of 62xxxx, 0xxxx, +62xxxx) used to resolve a session_id when none is given. Defaults to WSM_MCP_DEFAULT_PHONE when neither session_id nor phone is given.
- `collections` array — Collection names to resync; empty means waxum's default set.
- `mode` string — Resync mode.
- `target` string — Pin this call to one configured host by name (as listed in WSM_MCP_HOSTS), disabling failover for this call.
